# AutoProof

AutoProof é uma plataforma de vistoria digital de veículos desenvolvida para oficinas mecânicas, funilarias, centros automotivos e empresas que desejam registrar o estado de um veículo antes da execução de qualquer serviço.

O sistema gera um laudo completo com fotos, danos, observações e um link público para consulta, proporcionando maior transparência entre oficina e cliente e reduzindo riscos de reclamações indevidas.

## 🚀 Principais funcionalidades

- 📋 Cadastro de clientes e veículos
- 🔍 Criação de vistorias digitais
- 📷 Registro de fotos por peça do veículo
- 📝 Registro de danos e observações individuais em cada peça
- ✏️ Edição completa de vistorias mesmo após finalizadas
- 👥 Cadastro de funcionários vinculados à oficina
- 🔒 Sistema multiempresa (cada oficina acessa apenas seus próprios dados)
- 📊 Dashboard com estatísticas e vistorias recentes
- 🌐 Geração de laudo público compartilhável
- 📱 Interface responsiva para desktop, tablet e celular
- ☁️ Armazenamento seguro utilizando Supabase Storage
- 🔐 Autenticação de usuários via Supabase Auth

## 🎯 Objetivo

O AutoProof foi criado para proteger oficinas contra reclamações sobre riscos, amassados e outros danos pré-existentes, registrando digitalmente todas as condições do veículo antes do início do serviço.

Além da segurança jurídica, a plataforma melhora a organização interna da oficina e transmite maior profissionalismo ao cliente.

## 📄 Recursos do laudo

- Fotos em alta resolução
- Ampliação das imagens
- Identificação dos danos encontrados
- Observações por peça do veículo
- Resumo geral da vistoria
- Dados do cliente
- Dados do veículo
- Dados da oficina
- Código único da vistoria
- Link público para consulta
